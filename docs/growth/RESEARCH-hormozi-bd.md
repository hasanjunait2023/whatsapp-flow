# Research brief — Hormozi frameworks + BD competitive + $100M model

> Authored at M1 Foundation by researcher slice. Basis for the `hormozi-growth`
> skill, competitive wedge, and the honest $100M roadmap. Cited at bottom.

## Part A — Hormozi frameworks (actionable)

### A1. Value Equation
`Value = (Dream Outcome × Perceived Likelihood) / (Time Delay × Effort & Sacrifice)`
Raise numerator or shrink denominator. Never compete on price — compete on value.

### A2. Offer-building sequence
1. Define dream outcome (extreme specificity).
2. List every problem/obstacle (map each to a Value-Equation variable).
3. Reframe each problem as a named "how-to" solution.
4. Pick delivery vehicles per solution (attention 1:1/group/1:many · effort DIY/DWY/DFY · medium · speed · format).
5. Trim (cut high-cost/low-value) & stack into a named bundle priced on value.

### A3. Pricing/anchoring
Price on dream-outcome value, not cost-plus. Anchor each component's standalone
price before the bundle. Reveal bonuses AFTER commitment. Bonus stated value > core price.

### A4. Four guarantee types
Unconditional (try-then-pay) · Conditional (do-X-get-Y or refund/redo) ·
Anti-guarantee (all sales final, premium) · Implied/performance (paid on results).
State in writing; size to the prospect's biggest fear. (We use Conditional service guarantee.)

### A5. Scarcity & urgency (must be real)
Scarcity: limited seats / limited bonuses / never-again. Urgency: cohort-based,
seasonal, pricing/bonus deadline, closing window. Fake scarcity destroys trust.

### A6. MAGIC naming
Magnetic reason · Avatar · Goal · Interval · Container.
e.g. "5-Day F-Commerce Seller WhatsApp Automation Sprint."

### A7. $100M Leads — Core Four + loops
Lead magnet = free narrow-problem solver that reveals need for core offer.
7-step build: narrow painful problem → fast visible result → format (software/info/
service/physical) → MAGIC name → frictionless (<10 min to value) → one next step →
scarcity/urgency on CTA.
Core Four daily loops: Warm outreach (10–50/day, ask for intros, never cold-pitch) ·
Post content (1/day, max value/sec, soft CTA) · Cold outreach (50–100/day, personalize,
follow up 2–3×) · Paid ads (test creatives, 2× winners @72h, kill losers, retarget).
"Give-give-give until they ask." Lead-getters: customers (referral at peak-happiness
3-way intro) · employees · agencies · affiliates (whisper-tease-shout).
**Rule of 100:** one primary action, 100/day for 100 days before switching.

### A8. Money model
Client-Financed Acquisition: `Gross Profit(Day30) > 2 × (CAC + COGS)` → each customer
funds the next two. SaaS LTV:CAC ≥ 3:1 (healthy 5:1+), CAC payback < 12 mo.
SaaS stack: max Day-1 cash (annual upfront w/ 2-mo-free), max Day-30 profit (onboarding
upsell), max LTV (activation + churn reduction).

## Part B — BD WhatsApp-CRM competitive landscape

- **Tier 0 Manual** (largest): WhatsApp Business app (256 broadcast cap), manual FB/WA. Collapses past ~100 orders. Data only on Meta.
- **Tier 1 Unofficial bulk senders** (WA-Sender etc.): free–$20, scrape WA Web, high ban risk, no CRM.
- **Tier 2 Local API resellers** (WaTheta, WaCRM): ~৳500–2,000/mo, thin features, no Bangla UI, no courier.
- **Tier 3 BotSailor** (BD, Meta-verified BSP): chatbot/broadcast/catalog, Shopify/Woo, AI; free plan, paid from $10.99/mo, takes bKash; 120% YoY. Weak: not a full unified inbox, no BD courier integration, limited Bangla UX, no self-host. **Closest threat.**
- **Tier 4 MyAlice** (SG, BD-funded): unified inbox WA/FB/IG/TG/Viber, Shopify/Woo; $60–180/mo USD. Weak for BD: USD pricing, no bKash, no Bangla, no local courier.
- **Tier 5 Intl** (WATI $9.6M ARR / $35M raised; AiSensy ₹999/mo; Zoko): no real BD presence/BDT.

**The 5-dimension wedge none own together:** official API (ban-proof) + Bangla-first
UI/AI + BDT pricing & bKash/Nagad + native BD courier APIs (Pathao/RedX/Steadfast/
eCourier) + data ownership/self-host. ~12–24 month window before BotSailor could assemble it.

## Part C — Honest $100M model

BD TAM: ~100k–300k formal/semi-formal sellers (low-confidence); 50–80k payable.
Blended ACV ~$180/yr at current pricing → $100M needs ~555k BD customers >> TAM.
**BD-organic-only ceiling ~$5–15M ARR realistic, ~$40–90M theoretical.**

Levers: (1) ARPU climb (courier/AI/bulk/payment add-ons → ৳5–8k/mo); (2) **regional
expansion = primary path** (India social commerce $7.2B→$54B@22% CAGR; Pakistan;
MENA); (3) retention/LTV (SMB NRR ~97%, courier integration = switching cost).

**Roadmap:** P1 (0–24mo) BD 5–15k tenants @$15 → $0.9–2.7M ARR · P2 (24–48mo)
BD+India 30–60k @$20 → $7–14M · P3 (48–72mo) +PK+MENA 150–300k @$30 → $54–108M.
WATI signal: $9.6M ARR / 6k customers ⇒ ~$133/mo ARPU — SMB WhatsApp-CRM ARPU climbs
once value proven (favorable).

**Open risks:** BD seller-count + willingness-to-pay uncertain; WhatsApp Cloud API
per-conversation fees may exceed ৳899 platform fee for high-volume sellers (model
this); BotSailor response window 12–24mo; India GTM crowded (need courier-integration
differentiation, not price); BD data-localization regulation (self-host hedge).
